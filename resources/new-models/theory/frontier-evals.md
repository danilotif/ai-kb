# Frontier model eval comparisons

Where the closed and open frontiers actually sit on serious benchmarks. Updated as new models drop.

## The benchmarks worth tracking

*(MMLU-Pro, GPQA Diamond, AIME, SWE-bench Verified, LiveCodeBench, Aider polyglot, Tau-bench, ARC-AGI v2, FrontierMath)*

## Reasoning

*(o-series, Opus 4.x with thinking, Gemini 3 Pro thinking, DeepSeek R1, Qwen 3 reasoning; benchmarks: AIME, GPQA, FrontierMath)*

## Code

*(SWE-bench Verified, Aider polyglot, LiveCodeBench; current leaders, gap closing fast on open models)*

## Agentic / tool use

*(Tau-bench, GAIA, BrowseComp; agentic capability is where harness matters as much as model)*

## Long context

*(needle-in-haystack saturated; what's left: long-context reasoning (RULER, ZeroSCROLLS, Loft))*

## Multimodal

*(MMMU, MathVista, ChartQA; closed still ahead, open closing on standard benchmarks but lagging on the hardest)*

## Closed vs open frontier gap

*(narrowed sharply since 2024; on most benchmarks, gap is now <5 percentage points; on the hardest reasoning benchmarks, closed still ahead)*

## How to read these numbers

*(self-reported >> third-party; eval prompt format matters; pass@1 vs pass@k; tool-augmented vs raw)*
