# GPT-5.x family

OpenAI's current generation. What's in the lineup, what each is positioned for.

## Lineup

*(GPT-5, GPT-5 mini, GPT-5 nano, GPT-5 thinking; o-series reasoning still tracked separately on the Pro tier)*

## Reasoning vs non-reasoning

*(thinking tier toggles internal chain-of-thought + tool use; same model family, different default)*

## Capabilities

*(native multimodal in/out, real-time voice, code interpreter, browsing, function calling, structured output)*

## Context windows

*(typical 256K–1M depending on tier; what's actually usable in practice)*

## Pricing & rate limits

*(prompt caching ~50% off; batch API ~50% off; output tokens 4–5× input price)*

## API surface

*(Responses API as the new default, Chat Completions as legacy compatibility, Realtime API for voice)*

## How OpenAI positions vs Claude / Gemini

*(historically strong at general chat and code; Anthropic ahead on agentic coding; Google ahead on long-context multimodal)*
