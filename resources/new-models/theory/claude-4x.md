# Claude 4.x family

Anthropic's current generation. What each tier is for and how they differ.

## Opus 4.7 (1M context)

*(flagship; deepest reasoning; best agentic work; 1M-token context; highest cost per token)*

## Sonnet 4.6

*(balanced default; strong on code, agents, long-form synthesis; 200K context; ~5× cheaper than Opus)*

## Haiku 4.5

*(small/fast tier; cheap, low-latency; good at structured extraction, classification, summarization; agent worker tier)*

## How to pick

*(Haiku for high-volume narrow tasks; Sonnet as the default; Opus for hard reasoning, deep agent runs, and 1M-context jobs)*

## Pricing

*(per-million input/output tokens; cache hits ~10%; batch API ~50%)*

## Capabilities common to the family

*(extended thinking, tool use, vision, computer use, prompt caching, batch API, Files API, citations)*

## Extended thinking

*(`thinking` budget separate from output; longer thinking on Opus → much higher hard-task performance)*

## Computer use

*(Claude operates a virtual desktop; mouse, keyboard, screenshots; available across the family with Opus most reliable)*
