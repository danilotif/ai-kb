# Gemini 3.x family

Google DeepMind's current generation. Multimodal-native, long-context-first.

## Lineup

*(Gemini 3 Pro, Gemini 3 Flash, Gemini 3 Flash-Lite; thinking variants for hardest tasks)*

## Strengths

*(2M-token context; multimodal-native (image, audio, video, PDFs); strong on agentic tool use; tight Google product integration)*

## Weaknesses

*(formatting and follow-instruction precision lagged 4.x cycle; closing on 3.x; safety filters can be aggressive)*

## Pricing tiers

*(Flash-Lite for high-volume cheap; Flash as default; Pro for hard tasks)*

## API surfaces

*(Gemini API on AI Studio; Vertex AI for enterprise; same models, different auth/billing)*

## Long-context advantage

*(2M tokens reliably usable; whole-codebase or whole-corpus prompting feasible at Pro tier)*

## Multimodal

*(audio + video first-class; not just frames — temporal understanding; Veo for video gen, Imagen for image gen)*

## Tool use & agents

*(native function calling, code execution, Google Search grounding; Project Astra ambitions)*
