# Resources

A persistent KB of synthesized AI stories, organized by macro theme. Each story
that lives in `data/news.js` (the briefing rendered by the dashboard) is
mirrored here as a standalone markdown file so the knowledge survives across
`/update-news` refreshes.

## Layout

```
resources/
  frontier-models/         closed-weights flagship releases (OpenAI, Anthropic, Google, xAI, Meta proprietary)
  open-weights/            open-source / open-weights releases (DeepSeek, Qwen, Mistral, Gemma, Llama, etc.)
  agents-and-tooling/      MCP, agent frameworks, computer-use, coding agents
  business-and-infra/      capex, M&A, partnerships, hiring/layoffs, chip supply
  policy-and-safety/       regulation, government action, safety/security incidents
  research-and-evals/      notable arXiv papers, new benchmarks, eval methodology
```

A `products-and-features/` slot is reserved for the case where consumer-facing
ships (ChatGPT/Claude/Gemini/Copilot UX changes) need their own theme — create
the directory the first time it has content.

## File format

Each story is one markdown file. Frontmatter:

```yaml
---
date: YYYY-MM-DD       # max(source dates) for the story
theme: <macro theme>   # e.g. "Frontier model releases"
auto: true             # true if generated by /update-news; absent if hand-curated
---
```

Body: H1 with the headline, then prose, then a `## Sources` list (markdown
links). Filename pattern: `YYYY-MM-DD-short-slug.md` so listings sort
chronologically.
