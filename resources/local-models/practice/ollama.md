# Ollama

Daily-driver wrapper around llama.cpp with a model registry, daemon, and OpenAI-compatible API. The default for most local users.

## Install & first run

*(install on macOS / Linux / Windows; `ollama run llama3.2`)*

## Pulling and managing models

*(`ollama pull`, `ollama list`, `ollama rm`, tag conventions like `:7b-q4_K_M`)*

## Running a model

*(`ollama run`, system prompts, multi-line input, `/bye`)*

## Modelfiles

*(custom system prompt, parameter tweaks, importing a local GGUF, `ollama create`)*

## OpenAI-compatible API

*(`http://localhost:11434/v1`, drop-in for OpenAI SDKs, streaming)*

## Tuning

*(`OLLAMA_NUM_PARALLEL`, `OLLAMA_MAX_LOADED_MODELS`, `num_ctx`, GPU layer split, keep-alive)*
