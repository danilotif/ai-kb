# MCP quietly becomes enterprise plumbing

What started as an Anthropic protocol is showing up as default glue in
enterprise stacks. Adobe's CX Enterprise wraps agents, skills, and MCP
endpoints into a customer-experience platform; Databricks rolled out Unity AI
Gateway, extending Unity Catalog's governance to cover which agents can hit
which MCP servers and tools; and AdKit shipped an MCP service that lets
Claude/ChatGPT/Cursor drive Google and Meta ad campaigns end to end. None of
these are model launches — but together they signal MCP graduating from
protocol curiosity to the integration layer enterprises actually pay for.
